# JumpJet

JumpJet is a JavaScript compiler written in JavaScript. It compiles source text to JumpJet bytecode and executes that bytecode on its own virtual machine.

## Project direction

JumpJet is a self-hosting JavaScript compiler: it is written in JavaScript and compiles JavaScript to bytecode executed by its own virtual machine. The self-hosting milestone is reached when JumpJet can compile its own compiler source and run the resulting bytecode on the JumpJet VM.

The current priority is a clear, correct, and testable compiler architecture. High performance is not an initial feature goal.

See [ADR 0001](docs/adr/0001-language-and-execution-model.md) for the recorded decision.

## Current language slice

The first executable slice supports:

- Decimal numeric literals
- `let` declarations and identifier references
- Parenthesized expressions
- `+`, `-`, `*`, and `/` operators with precedence
- Semicolon-terminated statements
- The final expression statement as the program result

```js
import { compile, run } from "./src/index.js";

const result = compile("let answer = 1 + 2 * 3; answer;");

if (result.ok) {
    console.log(run(result.program)); // 7
} else {
    console.error(result.diagnostics);
}
```

## Commands

```sh
npm test       # Run unit and integration tests
npm run check  # Check JavaScript syntax
npm run demo   # Compile and execute the example program
npm run dev    # Start the browser editor at http://127.0.0.1:8000/main.html
```

## Browser editor

Start JumpJet Studio with `npm run dev`, then open
<http://127.0.0.1:8000/main.html> in a browser. Opening `main.html` directly as a
file will not work because the editor loads the compiler through browser modules.

In the editor you can:

- Write the currently supported JavaScript subset and select **編譯並執行**.
- Press Ctrl+Enter or Command+Enter to compile and run.
- Keep one browser-local draft with automatic or explicit saving.
- Import a `.js` file up to 1 MB.
- Download the current source as a `.js` file.
- Inspect the VM result, compiler diagnostics, and generated bytecode.

All compilation and storage happen locally in the browser. The editor does not
upload source code or execute it through the host JavaScript runtime.

## Compiler pipeline

```text
source
-> lexer
-> parser and AST
-> bytecode compiler
-> JumpJet bytecode
-> virtual machine
-> result
```

Compiler errors return source-positioned diagnostics. Invalid bytecode throws at the VM boundary. The compiler and VM do not use `eval` or `Function`.

The approved bootstrap specification is [Spec 0001](docs/specs/0001-bootstrap-javascript-bytecode.md).
The implemented browser editor specification is
[Spec 0002](docs/specs/0002-browser-editor.md).
