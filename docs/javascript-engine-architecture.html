A

A. 先回答 JumpJet 該選哪一種

結論

JumpJet 不需要在 V8、QuickJS 或 Hermes 中三選一。現階段應保留自己的 compiler 與 VM，以 QuickJS 和 Hermes 為主要架構參考。

JumpJet 現在是 bytecode-first interpreter。執行模型最接近 QuickJS 的 stack bytecode。Compiler artifact 與 self-hosting 路徑則更適合參考 Hermes。V8、JavaScriptCore 與 SpiderMonkey 的 JIT 分層可留到 profiler 證明有需要時再採用。

若目標改為「立即執行完整 JavaScript」，才應嵌入既有 engine。這會取代 JumpJet VM 的學習與 self-hosting 目標。

C

C. Bytecode-first 與 JIT 是不同問題

Engine Bytecode 形式 執行策略 最適合的情境
V8 Register-based 多層 tiered JIT Chrome、Node.js、高峰效能
QuickJS Stack-based Interpreter-only 小型嵌入、低啟動成本
JavaScriptCore Bytecode LLInt 加三層 JIT WebKit、Apple 平台
SpiderMonkey Stack-based Interpreter 加多層 JIT Firefox、可嵌入 JSAPI
Hermes Register-based AOT-first，可混用 interpreter 與 JIT React Native、mobile startup

「Bytecode-first」描述 compiler 產物。「Interpreter-only」和「tiered JIT」描述執行策略。V8 同時是 bytecode-first 與 tiered JIT，兩者並不衝突。

E

E. 嵌入 engine 與開發 engine 的差別

目標 做法 代價
立刻支援完整 JavaScript 嵌入 V8、QuickJS、JSC、SpiderMonkey 或 Hermes 自己的 parser、bytecode、VM 不再是執行核心
建立 self-hosting compiler 保留 JumpJet pipeline 必須逐步完成 functions、objects、closures 與 runtime
驗證共同語言 subset 用 Node 或其他 engine 做 differential test 只能比較共同支援的純語言語意
研究 JIT 先保留 bytecode contract，再量測 hot code 需要 profiler、machine-code backend 與 deoptimization

既有 engine 最適合當 reference oracle 或 host integration 範例。若直接用 V8 執行 JumpJet source，就不能證明 JumpJet VM 能執行自己的 compiler。

F

F. 建議的 JumpJet 下一層

下一個架構里程碑應是 BytecodeModule + FunctionRecord + verifier + Runtime + call frames。它能承接 function、closure、object 與 self-hosting。現在加入 SSA IR、register VM 或 optimizing JIT，會提早複製尚未穩定的語意。

G

G. Self-hosting 驗證路徑

Self-hosting 不要求 JIT。它要求 functions、call frames、strings、objects、closures 與 compiler 實際使用的 runtime library。Stage 1 與 stage 2 必須產生等價 bytecode，才算 compiler 能穩定編譯自己。

H

H. 何時才需要 JIT

先完成 self-hosting，再量測 opcode dispatch、property access、call、allocation 與 type check 的成本。如果 dispatch 是主要瓶頸，第一個 JIT 應模仿 Sparkplug 或 JSC Baseline，快速把 bytecode 轉成等價 machine code。

只有 type check 或 property lookup 佔主要成本時，才需要 inline cache、type feedback、optimizing IR 與 deoptimization。V8 透過 Maglev 與 TurboFan 處理這個階段。JumpJet 目前還沒遇到這類問題。V8 Maglev
