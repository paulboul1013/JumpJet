B. Compiler 資料流

每個邊界只回答一類問題。Lexer 判斷字元如何組成 token。Parser 建立語法結構。Analyzer 判斷名稱與修改是否合法。Emitter 選擇對應指令。VM 驗證並執行 bytecode。

D

D. Bound model 與責任

Analyzer 只會回傳 diagnostic 或 bound program。Bound identifier 含有 slot。Bound assignment 含有 slot 與賦值內容。宣告記錄 slot 與宣告種類。Emitter 因此不會收到非法的 const 修改。

E

E. 條件分支 bytecode

JumpIfFalse 會消耗 condition。Jump 會改變 instruction pointer。Duplicate 保留 assignment 的結果，之後 StoreSlot 只消耗其中一份。

G. 正確性驗證
